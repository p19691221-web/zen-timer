# 禪修計時器

單一網頁的禪修計時器，不需安裝、沒有廣告、不用登入。

## 功能

- **分段流程**：坐禪、經行、止靜、休息，可自由增減；內建「一支香 30 分」「坐 25・行 10・坐 25」「晨坐 15 分」。
- **磬聲**：開始與結束響磬（次數可調），換段響一聲，可設中途提示磬。磬聲以瀏覽器合成，不需音檔。
- **開始前準備**：預設 10 秒，讓你坐定。
- **暫停 / 提前結束**。
- **修行紀錄**：每座結束可留一句筆記；顯示總座數、近七日分鐘、連續天數；可匯出 CSV。

## 隱私

設定與紀錄只存在自己裝置的瀏覽器（localStorage），不上傳任何伺服器。清除瀏覽器資料或換手機會消失，請定期匯出。

## 限制

- 手機鎖定螢幕後，瀏覽器可能暫停計時與磬聲。頁面會嘗試保持螢幕亮著（Wake Lock），建議接上電源、調低亮度。
- 第一次按「開始」後才能發聲（瀏覽器規定）。

## 部署

Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
